Tailwind to CSS

Utility classes to plain CSS

Paste a string of Tailwind utility classes and get the equivalent plain CSS, grouped into a single rule. This covers a solid set of common utilities using the default theme values. It is not the whole framework and does not resolve plugins or custom config.

Everything runs locally in your browser. No external dependencies, works offline.
